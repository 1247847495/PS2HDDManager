# PS2HDDManager
# PS2 硬盘管理工具（PS2HDDManager）

**V1.3Beta**  作者：ANYI&明天会更好

PS2 硬盘游戏一站式管理工具：HDL / +OPL 游戏安装、PS1 VCD 安装、硬盘启动、封面下载、金手指配置、分区修复等。

## 运行要求

- .NET Framework 4.0+（Win7 SP1 及以上系统均自带，无需安装）

- 以管理员身份运行

- Win7/8 如中文标题显示异常才需考虑 UTF-8 兼容性，Win10/11 完全没问题

## 下载

直接下载本仓库中的 `PS2HDDManager.exe` 即可。软件内点"关于与更新"可自动检查新版本并在线更新。

## 使用注意

安装 HDL 游戏时如遇软件卡死，等 10 分钟后再关闭软件，游戏一样可以安装成功；切记不要一出现无响应就立刻关闭。
